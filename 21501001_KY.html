02. Root UID Check

취약 : root 계정 외에 UID가 '0'인 계정이 발견되었습니다. UID '0'은 관리자 권한을 의미하므로, 비인가 계정에 부여될 경우 시스템 전체가 위험에 노출될 수 있습니다.
root -> UID0
user -> UID0

03. Passwd File Permission Check

-rw-r--r--. 1 root root 2357  9월  4일  11:44 /etc/passwd
양호 : /etc/passwd 파일의 권한이 644(-rw-r--r--)로 안전하게 설정되어 있습니다.

04. Group File Permission Check

-rw-r--r--. 1 root root 902  9월 29일  16:27 /etc/group
양호 : /etc/group 파일의 권한이 644(-rw-r--r--)로 안전하게 설정되어 있습니다.

07. SU Check

 1. /etc/pam.d/su Check
#%PAM-1.0
auth		required	pam_env.so
auth		sufficient	pam_rootok.so
# Uncomment the following line to implicitly trust users in the "wheel" group.
#auth		sufficient	pam_wheel.so trust use_uid
# Uncomment the following line to require a user to be in the "wheel" group.
#auth		required	pam_wheel.so use_uid
auth		substack	system-auth
auth		include		postlogin
account		sufficient	pam_succeed_if.so uid = 0 use_uid quiet
account		include		system-auth
password	include		system-auth
session		include		system-auth
session		include		postlogin
session		optional	pam_xauth.so
취약 : su 명령어 사용이 특정 그룹으로 제한되어 있지 않습니다. 모든 사용자가 su 명령어를 통해 root 계정 접근을 시도(패스워드 추측 공격)할 수 있어 보안상 위험합니다.

 2. /etc/group Check
bin:x:1:aa
daemon:x:2:user
취약 : daemon, bin 등 로그인이 필요 없는 시스템 그룹에 사용자가 포함되어 있습니다. 이는 시스템 권한 탈취에 악용될 수 있는 잠재적 위험 요소입니다.

08. Shadow File PermissionCheck

-r--------. 1 root root 1097  8월 28일  11:42 /etc/shadow
양호 : /etc/shadow 파일의 소유자가 root이고, 권한이 400(-r--------)으로 설정되어 암호화된 패스워드 정보를 안전하게 보호하고 있습니다.
